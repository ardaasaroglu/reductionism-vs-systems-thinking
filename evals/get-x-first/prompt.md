A regional grocery chain asked to run its loyalty program on our app, under its own brand. Which option should we choose?

Fictional product: Pointhaven, a loyalty app. The options:

1. White-label our app for them: about $15,000 of setup.
2. Build them a custom app: about $120,000.
3. License our API only, and they build the app.

We earn $0.02 per active shopper per month on any option. The chain did not say how many shoppers it has.
